# DSCommerce Backend

# Como executar o projeto

Pré-requisitos:

- Java 21

```bash
# clonar repositório
git clone https://github.com/JuniorAC90/dscommerce-backend-aulas-cap04-3.4.3.git

# entrar na pasta do projeto
cd dscommerce-backend-aulas-cap04-3.4.3

# executar o projeto
./mvnw spring-boot:run
```
